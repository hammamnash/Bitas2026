# Diagrams

## Overview

SAP LeanIX
provides enterprise architecture diagramming tools that connect directly to your
inventory. These tools help you visualize and manage the complexity of your
organization's IT landscape. With integrated editors, you can create diagrams and
templates that illustrate relations and data flows. You can also link diagrams to
real inventory elements for accurate, dynamic architecture insights.

## Diagram Types

- [Free Draw Diagrams](https://help.sap.com/docs/leanix/ea/free-draw?locale=en-US&state=PRODUCTION&version=CLOUD "Free draw diagrams provide a flexible canvas for creating custom visualizations of your enterprise architecture, including organizational structures, capability maps, and system landscapes. Use them to support strategic planning, stakeholder communication, and collaborative design."):
Create custom architecture diagrams with linked shapes and connectors.

- [Data Flow Diagrams](https://help.sap.com/docs/leanix/ea/data-flow?locale=en-US&state=PRODUCTION&version=CLOUD "Data flow diagrams visualize how data moves between applications and their interfaces. Use them to plan application replacements, design integrations, assess compliance risks, and optimize data flows between systems."): Map
directional data exchanges and interface dependencies between applications.

- [Target Architecture Diagrams](https://help.sap.com/docs/leanix/ea/target-architecture-diagrams?locale=en-US&state=PRODUCTION&version=CLOUD "Visually design your target IT landscape before syncing changes to the inventory. Create transformations and compare current and target states with the architectural changes."):
Design and communicate future-state architectures.

- [Lucidchart Integration](https://help.sap.com/docs/leanix/ea/lucidchart-integration?locale=en-US&state=PRODUCTION&version=CLOUD "Seamlessly link SAP LeanIX to Lucidchart to extended visual modeling."):
Create, import, export, and edit Lucidchart diagrams in SAP LeanIX.


To learn more about each diagram type and its primary use case, see [Diagram Types](https://help.sap.com/docs/leanix/ea/diagram-types?locale=en-US&state=PRODUCTION&version=CLOUD "SAP LeanIX provides several diagram types for visualizing and planning enterprise architecture: free draw diagrams, data flow diagrams, target architecture diagrams, and Lucidchart diagrams.").

## Benefits

- Visualize and communicate architecture: Create as-is and
target architecture diagrams to illustrate data flow, dependencies, and
relations. Embed diagrams in presentations to engage stakeholders and support
informed decisions.

- Explore and customize: Drill down into details, explore
dependencies, and customize diagrams by adding shapes or images, even for
elements not represented in the inventory.

- Ensure consistent, up‑to‑date architecture views: Access,
create, and link fact sheets directly within diagrams to keep architecture and
inventory data in one place. Receive notifications about inventory changes and
choose when to refresh your diagram.

- Define reusable rules for data visualization: Use diagram
templates to create standardized diagrams that reflect the current state of your
inventory. Create fixed, editable diagrams when you need point‑in‑time
documentation, sharing, or audits.

- Track and share progress: Save different versions of
diagrams to capture architecture over time. Include them in dashboards, fact
sheets, and presentations to share insights and monitor changes.


## Difference Between Diagrams and Reports

| Feature | Diagrams | Reports |
| --- | --- | --- |
| Purpose | Visual storytelling. Use to show topology, relations, data flows,<br>interfaces, or target-state sketches for workshops and stakeholder<br>alignment. | Tabular analysis. Use for counts, aggregations, filters, saved<br>views for audits and decision-making. |
| Best For | When structure, flow, and visual context matter more than counts<br>or lists. | When you need repeatable slices of data, such as drill-downs or<br>KPIs, for tracking and reporting. |
| Output Format | Interactive canvas with shapes, connectors, and layout. | Tables and charts. |

## Difference Between Viewing and Editing Diagrams

In LeanIX, you work with diagrams in two functional states:

- Viewing: This is the default view when you open a diagram
from the Diagrams tab. In this view, you can explore and
manage the diagram as published content. You can navigate, inspect data, use
version history, restore versions, export, and share diagrams.

- Editing: Editing happens in the diagram editor, which you
open by clicking Edit in the top-right corner of the
Diagrams section. In this view, you can design and
modify the diagram structure. You can add shapes and connectors, link to fact
sheets, and save changes.


| Capability | Viewing | Editing |
| --- | --- | --- |
| Create new diagrams | No | Yes |
| Modify shapes/connectors | No | Yes |
| Link elements to fact sheets | No | Yes |
| Use templates and shape libraries | No | Yes |
| Apply inventory updates | No | Yes |
| Rename diagrams and update metadata | Yes | No |
| View metadata (owner, dates, sharing) | Yes | No |
| Edit fact sheet fields | Yes | No |
| Access version history | Yes | No |
| Restore previous version | Yes | No |
| Open linked fact sheets | Yes | Yes |
| Export as image or PDF | Yes | Yes |
| View inventory updates | Yes | Yes |

## Finding and Organizing Diagrams

Search, filter, and sort functions help you streamline navigation, save time, and
maintain better control over large sets of diagrams.

- Search and filter by ownership, read and write
permissions, creation date, modification date, and diagram type.

- Sort diagrams by attributes such as name, date, or
relevance to find what you need faster.

- Switch between grid view (visual browsing) and
list view (tabular details) depending on how you want
to work with diagrams.


## Adding Diagrams to Your Favorites

You can add a diagram to your favorites to access it quickly. To add a diagram to
your favorites, choose the star icon on the diagram card or next to the diagram’s
name. When a diagram is added to your favorites, the star turns blue.

Access your favorite diagrams in the Favorites section under
Diagrams \> Personal.

To remove a diagram from your favorites, choose the blue star icon.
