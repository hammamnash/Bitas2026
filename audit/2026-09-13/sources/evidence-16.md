# Joule in SAP LeanIX

Joule is an AI assistant in SAP that helps you access resources and find information
through conversational interactions. Learn how to access it and leverage its
features.

## Overview

Joule is a generative AI assistant in SAP’s ecosystem that
understands user requests through conversational interactions, retrieves relevant
information, and assists you in completing your tasks.

Joule helps you access resources such as fact sheets, reports, or diagrams without
manual navigation. While such actions are available in SAP LeanIX, you
can also use Joule to find information across other areas of the SAP ecosystem where
Joule is accessible.

## Capabilities

| Area | Description |
| --- | --- |
| Diagrams | Search for diagrams in SAP LeanIX. Open a diagram directly from the conversation or bring it in as<br>context. |
| Reports | Search for reports in SAP LeanIX. Open a report directly from the conversation, or bring it in as<br>context. |
| Fact sheets | Search the inventory by fact sheet name, by applying filters, or<br>using natural language. If you have the required permissions, you<br>can create, update, or archive fact sheets without leaving the<br>conversation. You can update the fact sheet name, description,<br>lifecycle, and quality seal from the conversation. |
| Subscriptions | View fact sheet subscribers and their roles, and contact them<br>directly from the conversation. |
| To-dos | Open a fact sheet to view related to-dos and their status. Create<br>new to-dos without leaving the conversation. |
| Architecture insights | Ask for architecture guidance and receive insights that provide<br>actionable recommendations and improvement suggestions. |
| Transformations | Browse transformation types and search the transformation<br>inventory using terms relevant to your question. |
| Strategic initiatives | Search for strategic initiatives and view their details from the<br>conversation. |
| Users | Find users by name or email and see which fact sheets they’re<br>subscribed to. |
| Architecture decisions | View architecture decisions and browse decision templates. Create<br>new decisions by providing sufficient context in the conversation. |
| Surveys | Search survey runs and view results and recipient lists. Create<br>new surveys by specifying a creator, due date, and scope. |
| Documentation | Ask questions about SAP LeanIX and get answers based on the documentation. Joule summarizes<br>information and offers a direct link to the source. If no direct<br>information is found, Joule attempts to answer using its training<br>data. |

## Accessing Joule

To access Joule in SAP LeanIX,
click the diamond-shaped icon in the upper-right corner, next to the user profile
menu. Type your message to start a conversation.

To learn more about setting up Joule, see [Integrating Joule with SAP Solutions](https://help.sap.com/docs/joule/integrating-joule-with-sap-solutions-eac-4d4f3bd714d443f194732c43d0c51b54/introduction?locale=en-US&version=CLOUD "https://help.sap.com/docs/joule/integrating-joule-with-sap-solutions-eac-4d4f3bd714d443f194732c43d0c51b54/introduction?locale=en-US&version=CLOUD").
